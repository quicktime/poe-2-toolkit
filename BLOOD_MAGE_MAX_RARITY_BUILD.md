## 💰 FARMING STRATEGY

### Best Maps for MF:
1. **Tower** - High density, good cards
2. **Burial Chambers** - Doctor card chance
3. **Cemetery** - Dense, easy layout
4. **Arcade** - Good div cards
5. **Tropical Island** - High pack size

### Map Rolling:
- **Quantity**: 80%+
- **Rarity**: 25%+
- **Pack Size**: 20%+
- **Avoid**: No regen, reflect

### Farming Rotation:
1. Run 20-30 maps with full MF gear
2. Collect all rares and uniques
3. ID good bases
4. Vendor trash for currency
5. Reinvest into better rarity gear
